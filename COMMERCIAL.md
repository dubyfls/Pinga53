# Commercial licensing

Pinga53 is free for people. If you make money with it, you pay.

## When you need a commercial license

| You want to... | Free license is enough? | Need |
| --- | --- | --- |
| Protect your own home, family or non-profit network | Yes | nothing |
| Change the code and publish your changes under AGPL-3.0 | Yes | nothing |
| Run a changed version for others **without** publishing your source | No | Commercial code license |
| Ship Pinga53 code inside a closed product, appliance or firmware | No | Commercial code license |
| Use Pinga53 Data in any commercial product, service or company network | No | Commercial data license |
| Resell, bundle or redistribute Pinga53 Data commercially | No | Commercial data license |

The code license is [AGPL-3.0-only](LICENSE). The data license is
[CC BY-NC-SA 4.0](LICENSE-DATA.md), which allows no commercial use.

## What a commercial license gives you

- the right to use and modify the code without the AGPL's source-sharing
  obligations;
- the right to use Pinga53 Data commercially;
- terms, price and support agreed in writing with the owner.

A commercial license from Pinga53 does **not** grant rights to third-party
feed data. Commercial users need their own agreements with providers whose
terms require one (for example, abuse.ch commercial use needs a Spamhaus
subscription, and the OpenPhish community feed is personal use only).

## Contact

Open an issue at <https://github.com/dubyfls/Pinga53/issues> titled
**"Commercial license"**. Don't post confidential details there; the owner
will reply with a private channel.

Until a written agreement is signed, the only rights you have are those in
the free licenses.
