Pinga53 Data is any dataset that the Pinga53 project itself publishes,
including:

## Third-party data is not Pinga53 Data

Pinga53 does not ship third-party feed data and does not relicense it.
Each installation downloads feeds directly from their providers, and that
data stays under each provider's own terms (see the README's source
table). This license covers only what the Pinga53 project itself publishes.
